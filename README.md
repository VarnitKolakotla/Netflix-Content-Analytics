# Netfix-Content-Analytics
📌 Project Overview

The Netflix Content Analytics Dashboard is a data visualization project developed using Tableau to analyze Netflix movies and TV shows. It provides insights into content distribution, release trends, country-wise representation, content ratings, and movie durations.

The project uses the Netflix dataset to transform raw data into interactive visualizations that make it easier to understand patterns in Netflix's content catalogue.

🎯 Objectives
Analyze the distribution of movies and TV shows on Netflix.
Identify the countries contributing the most content.
Examine Netflix content release trends over time.
Analyze content ratings and their distribution.
Explore movie duration patterns.
Visualize the global distribution of Netflix content using a world map.
📊 Dataset Description

The project uses the Netflix titles dataset (netflix.csv).

Total records: 8,807
Total columns: 12
Content types: Movies and TV Shows
Important attributes: Title, Type, Director, Cast, Country, Date Added, Release Year, Rating, Duration, Genre, and Description.
🛠️ Tools and Technologies
Tableau: Dashboard development and data visualization.
Microsoft Excel / CSV: Dataset inspection and preparation.
GitHub: Project documentation and file management.
📈 Dashboard Visualizations

The dashboard includes the following visualizations:

KPI Cards: Display the total number of titles, movies, and TV shows.
Movies vs. TV Shows: Compares the distribution of movies and TV shows.
Content Ratings: Shows the distribution of Netflix titles by rating.
Netflix Titles Added by Year: Examines how the number of titles added changes over time.
Content by Original Release Year: Compares movie and TV show release-year trends.
Top 10 Countries by Netflix Content: Identifies countries most represented in the dataset.
Movie Duration Distribution: Examines the distribution of movie runtimes.
Global Distribution Map: Visualizes the countries associated with Netflix content.
🔍 Key Insights
The dataset contains 8,807 titles.
Movies account for 6,131 titles, while TV shows account for 2,676 titles.
Movies represent approximately 69.6% of the dataset, while TV shows represent 30.4%.
The United States is the most frequently represented country in the dataset.
TV-MA is the most common content rating, followed by TV-14.
Movie durations are concentrated around approximately 90–120 minutes.
The number of titles added to Netflix increased substantially between 2016 and 2019 in the dataset.

Note: These findings describe the supplied dataset and do not measure actual viewership or popularity.
